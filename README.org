* Imake — a simple, opinionated make target runner

This package provides the command ~imake~, which prompts for
~make~ targets and runs them in the current directory.

If targets are documented as shown below, using one or more
targets whose names begin with "help", then that documentation
is shown.

#+begin_src text
  help helpall::
	  $(info make lisp   - generate byte-code and autoloads)
  help::
	  $(info make clean  - remove generated files)
#+end_src
